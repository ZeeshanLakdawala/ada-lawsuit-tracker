# Code of Conduct

## Our standard

We want this project to be useful, respectful, and safe for everyone. Participants must communicate in good faith and treat other people with respect.

Examples of behaviour that are not acceptable include harassment, personal attacks, discrimination, threats, unwanted sexual attention, publishing private information, and deliberately disrupting project discussions.

## Project spaces

This policy applies to GitHub issues, pull requests, discussions, reviews, and project-related communication.

## Enforcement

Report a problem to the repository maintainer through a private GitHub message or the contact method listed in the repository profile. Include what happened, where it happened, and any useful context. Reports will be reviewed and handled as privately as possible.

The maintainer may remove comments, close discussions, reject contributions, or restrict participation when behaviour violates this policy.

## Scope

This Code of Conduct is adapted from the Contributor Covenant community standard. It applies whenever someone is acting as a project participant or representing the project.
